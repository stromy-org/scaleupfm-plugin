Install (about five minutes)

Open Copy full signature, press Cmd+A then Cmd+C (Ctrl+A, Ctrl+C on Windows). Paste it with Cmd+V (Ctrl+V) into the signature box, then do the same with Copy reply signature.

  • Outlook on the web (outlook.office.com): Settings (gear) → Account → Signatures (older layout: Mail → Compose and reply). Add ScaleUp full and ScaleUp reply, pick the full one for new messages and the reply one for replies and forwards, save.
  • Outlook on the laptop: new Outlook (Mac or Windows) uses the same Settings → Account → Signatures and syncs with the web. Classic Outlook for Windows: File → Options → Mail → Signatures. Legacy Outlook for Mac: Outlook → Settings → Signatures. Choose the ScaleUp account as the one the defaults apply to.
  • Outlook on the phone: Settings → Signature, pick the ScaleUp account and paste the text version (the phone app keeps its own, simpler signature).

Then send one mail to yourself and check: the logo shows, there is no attachment icon, and the links open.
